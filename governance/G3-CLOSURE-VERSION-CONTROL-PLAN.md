## 1 · THE PROBLEM THIS PLAN EXISTS TO SOLVE

The approved G3 work is spread across **three locations with three different
version-control states**, measured today:

| location | git state | what G3 keeps there |
|---|---|---|
| `04 Deploy/plotnua-github` | **repo** · `origin git@github.com:colin-macaulay-dcu/plotnua.git` · `main` @ `30b49d8` · holds `.github/workflows`, so this is the deploying repo | the journey page (tracked, modified), 4 builders + 1 proof (untracked), `governance/` (untracked) |
| `03 Website/Live Website` | **separate repo** · `master` @ `5bc1eae` | the certified Airtable schema and register contract (**tracked**), the Phase-2 decision report (**untracked**) |
| `04 Deploy/plotnua-garden-register` | **NOT a repo, and not inside one** | the deployed Worker, `wrangler.toml`, and all five proof suites — **no version history at all** |

The consequence, stated plainly: **the Worker that will one day hold real
homeowner data cannot be diffed against a committed source, and the suites that
prove it safe would be gone if the directory were lost.** That is PS-2 in the
public-switch checklist, and it is the single most consequential item here.

## 3 · WHERE THINGS SHOULD LIVE — RECOMMENDATION

**Keep the journey page, builders and governance where they already are**, in
`plotnua-github`. That repo deploys the site and already holds the page; moving
any of it would be change for its own sake.

**The real decision is the Worker.** Three options:

| option | for | against |
|---|---|---|
| **A · a `worker/` directory inside `plotnua-github`** (recommended) | one repo, one history; the page and the endpoint it calls are versioned together, so a change to either is visible in one diff; no new remote, no new access to manage | mixes a Cloudflare Worker into a Pages repo; the `.github/workflows` there must be confirmed not to pick it up |
| **B · its own repository** | clean separation of a separately-deployed service; independent history | a second repo to keep in step; the page/endpoint contract then spans two histories, which is exactly how the two drift apart |
| **C · leave it unversioned** | nothing to do | **reject.** This is PS-2, and it gets worse the moment real data is involved |

**Recommended: A.** The page and the Worker are one contract — the consent
sentence is hashed on both sides, and the vocabularies must match exactly. Two
histories make that invariant harder to hold, not easier.
